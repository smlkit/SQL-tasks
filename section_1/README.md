- `JOIN`

- `RIGHT JOIN`
- `ANTI JOIN`
- `SELF JOIN`
- агрегатных функций

- `CTAS`
- оконных функций

> **Database:** PostgreSQL  
> **Difficulty:** Intermediate → Advanced

Задания специально не являются простыми упражнениями вида «выведи все имена». Большинство задач требуют комбинировать несколько SQL-конструкций.

# Database Schema

Схема представляет собой небольшой интернет-магазин.

```text
customers
    │
    ├──────────────< orders ──────────< order_items >──────── products
    │                     │                                  │
    │                     │                                  └──── categories
    │                     │
    │                     └──────── payments
    │
    ├──────────────< customer_addresses
    │
    └──────────────< product_reviews >──────── products


employees
    │
    └──── SELF JOIN через manager_id
```

# Tasks

## 1. JOIN

### Task 1 — Order Revenue

Для каждого завершённого заказа рассчитать:

- `order_id`
- имя клиента
- дату заказа
- стоимость заказа до скидки
- стоимость заказа после скидки

Использовать:

- `customers`
- `orders`
- `order_items`

---

### Task 2 — Customers Without Orders

Найти клиентов, которые зарегистрировались, но **ни разу не сделали заказ**.

Вывести:

- клиента
- дату регистрации
- количество заказов

Клиенты без заказов обязательно должны присутствовать в результате.

Использовать `LEFT JOIN`.

---

### Task 3 — Products Never Sold

Найти товары, которые **никогда не продавались**.

Решить задачу через `ANTI JOIN`:

- `NOT EXISTS`
- или `LEFT JOIN ... IS NULL`

---

### Task 4 — Completed Orders

Для каждого клиента посчитать количество завершённых заказов.

Клиенты без завершённых заказов тоже должны попасть в результат.

Использовать `LEFT JOIN`.

Обрати внимание, куда помещается условие:

```sql
orders.status = 'completed'
```

в `ON` или в `WHERE`.

---

### Task 5 — Categories With No Sales

Получить список всех категорий и количество проданных единиц товаров в каждой категории.

Категории, в которых ничего не продавалось, должны присутствовать.

Решить задачу через `RIGHT JOIN`.

---

### Task 6 — Product Profitability

Для каждого товара рассчитать:

- категорию
- количество проданных единиц
- выручку
- себестоимость
- валовую прибыль

Учитывать только завершённые заказы.

Использовать минимум четыре таблицы:

```text
products
categories
order_items
orders
```

---

### Task 7 — Employee Hierarchy

Для каждого сотрудника отдела `Sales` вывести:

- сотрудника
- его руководителя
- отдел руководителя
- зарплату сотрудника
- зарплату руководителя
- разницу в зарплатах

Использовать `SELF JOIN`.

---

### Task 8 — Employees Earning More Than Their Managers

Найти сотрудников, чья зарплата выше зарплаты их руководителя.

Использовать `SELF JOIN`.

---

### Task 9 — Detailed Sales Report

Создать отчёт по каждой позиции заказа:

- клиент
- заказ
- товар
- категория
- сотрудник продаж
- количество
- цена
- сумма позиции
- способ оплаты

Использовать минимум 5 таблиц.

---

### Task 10 — Category Performance

Для каждой категории рассчитать:

- количество уникальных товаров
- количество проданных единиц
- выручку
- среднюю цену продажи

Оставить только категории, где:

- продано больше 3 единиц
